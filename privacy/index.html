プライバシーポリシー

収集する情報

本サイトは静的なウェブサイトで、会員登録・コメント・問い合わせフォームはありません。訪問者が本サイトに直接入力する情報はありません。

本サイトは GitHub Pages（GitHub, Inc.）で配信しています。同社が配信のためにアクセスログ（IP アドレス、ブラウザの種類、閲覧日時、閲覧ページなど）を記録することがあり、その取り扱いは同社のプライバシーポリシーに従います。

Cookie と localStorage

本サイトは Cookie を使用しません。

ただし、表示テーマ（ライト／ダーク）の選択を記憶するため、お使いのブラウザの localStorage に設定値を 1 件保存します。この情報が外部に送信されることはありません。ブラウザの設定でいつでも削除できます。

外部サービス

現時点で、第三者によるアクセス解析サービスや広告配信サービスは利用していません。導入した場合は本ページに追記して告知します。

免責事項

本サイトの内容は正確を期していますが、その正確性・完全性・安全性を保証するものではありません。本サイトの情報を利用したことによって生じた損害について、本サイトは責任を負いません。

本サイトからリンクしている外部サイトの内容についても、本サイトは責任を負いません。

本ポリシーの改定

本ポリシーは予告なく改定することがあります。改定後のポリシーは、本ページに掲載した時点から効力を持ちます。
